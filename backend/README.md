# Backend Application - NestJS + TypeScript + Prisma ORM + PostgreSQL + Redis

This directory contains the enterprise-grade REST APIs, WebSockets, Prisma ORM schema, and background jobs logic for Stiqr.

## Running Locally

```bash
# Install dependencies
pnpm install

# Start NestJS Development Server
pnpm dev
```
Server runs at `http://localhost:4000/api`.
